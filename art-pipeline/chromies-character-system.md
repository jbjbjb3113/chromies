## Character System (Locked)

### Character Trait — Top-Level Roll

Before any slot rolls, a Character is picked. Character gates palette pool,
forced slots, and eligible variants.

### Gender Split

Male/Female is expressed through head/neck variants, not a separate trait axis.
55% Male (HeroA), 45% Female (HeroA) within the human pool.

### Per-Character Rules (Locked)

**HeroA Male** — full palette pool, all slots eligible, standard weights.

**HeroA Female** — full palette pool, all slots eligible. Beard/mustache weights
reduced (rare, not zero — bearded lady is a valid rare).

**Alien** — locks to ALIEN palette. Forces Hair=None. Uses BODY_Alien (own body
asset). No beard/mustache.

**Cat** — TBD on palette restrictions. TBD on slot overrides. Asset pending.

**Agent** — TBD on palette restrictions. TBD on slot overrides. Asset pending.
